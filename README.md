# Faith in Others

This is a static website. Open `index.html` to see the page structure and text. `styles.css` controls its appearance, `app.js` runs the theme and starting-point buttons, and `assets/` holds the image and icon.

The feedback form in `index.html` posts to the Formspree endpoint you supplied. It collects page feedback, not newsletter subscriptions.

To put the source on GitHub, extract this ZIP and upload its contents to a private repository. Keep `index.html`, `styles.css`, `app.js`, and `assets/` together at the repository's top level. Uploading this ZIP file alone will not display the site as code files on GitHub.

This is a copy of the source, not a live connection to the existing private Sites page. Editing GitHub will not automatically update that page. GitHub Pages is a separate publishing step.
